## Deployment Steps on Live Server

Step 1: Backup current codebase & database
------------------------------------------
python manage.py dumpdata --natural-foreign --natural-primary -e contenttypes -e auth.Permission --indent 4 > pre_update_backup.json

Step 2: Extract Zip Package
---------------------------
unzip -o admission_online_and_login_refactor_live_update.zip -d /path/to/project/root/

Step 3: Run Database Migrations
-------------------------------
python manage.py migrate students

(Expected applied migrations: 0029_admissionintake_onlineapplicant, 0030_alter_student_uniform_status)

Step 4: Collect Static Files
----------------------------
python manage.py collectstatic --noinput

Step 5: Seed 2 Test Students for Winter 2027 (Optional / Recommended for Testing)
-------------------------------------------------------------------------------
python manage.py seed_winter_2027_test_applicants

This will:
- Check for "Winter 2027" intake (or create it with future deadline if not present)
- Create 1 Approved applicant: Nafis Fuad (OA-W27-00101, Roll: BAUST-W27-1001)
- Create 1 Pending applicant: Sumaiya Tasnim (OA-W27-00102)

Step 6: Verify System Check
---------------------------
python manage.py check

Step 7: Restart Application Server / Daemon
-------------------------------------------
sudo systemctl restart gunicorn
# or
sudo systemctl restart uwsgi
# or reload supervisor / cPanel passenger
