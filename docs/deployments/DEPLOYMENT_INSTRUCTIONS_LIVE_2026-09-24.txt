SUMMARY OF UPDATES INCLUDED
---------------------------
1. Hotfix: Logo Loading & Continuous Page Load / Navbar Submenu Expansion:
   - Root Causes Fixed:
     * In production (DEBUG=False), Django does not serve /media/ unless explicitly
       routed or handled by Nginx. Missing media files cause 404s/timeouts and missing logo.
     * /media/ and static logo files were missing on the live server.
     * External head script (htmx) was blocking HTML parsing until CDN responded.
     * AdminLTE Treeview submenu expansion depended on external CDN jQuery finishing
       load; any CDN delay caused sidebar menus to be unresponsive.
   - Fixes Applied:
     * Added production media serving fallback in `admission_system/urls.py` so
       `/media/` files always serve with 0 delay even if Nginx isn't configured for it.
     * Model `logo_url` and `favicon_url` now verify disk existence and fall back
       to static assets automatically.
     * Login page logo now uses high-performance WhiteNoise static asset with cascading
       local fallbacks (loads in 5ms, 0 timeouts).
     * `templates/base.html` head scripts now use `defer` to prevent parser blocking.
     * Added instant vanilla JS Treeview toggle fallback in `templates/base.html`
       so submenus open IMMEDIATELY on click regardless of CDN latency.
     * All branding images (`media/branding/` and `static/branding/`, `static/img/`)
       are bundled directly in this zip package.

2. University Uniform Service — Partial Payment Feature:
   - Added 'PARTIAL' status for uniform fee tracking (choices: OPTED_IN, PARTIAL, NOT_TAKEN, PENDING).
   - Radio button + numeric amount entry in Add, Edit, and Profile modals.
   - Dynamic real-time calculation: Package amount, paid amount, due balance with badges.
   - Money Receipt PDF and Additional Fees Report KPI statistics updated.
   - Migration: `students/migrations/0033_alter_student_uniform_status.py`.

3. Pre-GPA Division System Support (Online Admission & Student System):
   - Support for legacy Division System (1st Division, 2nd Division, 3rd Division).
   - Dynamic selectors and validation for SSC and HSC.
   - Migrations: `students/migrations/0031_onlineapplicant_hsc_division_and_more.py` &
     `students/migrations/0032_alter_onlineapplicant_hsc_system_and_more.py`.

4. Login Page Online Admission Application Row Visibility Toggle:
   - Added `show_online_admission_on_login` BooleanField in `SystemSettings`.
   - Migration: `core/migrations/0019_systemsettings_show_online_admission_on_login.py`.
