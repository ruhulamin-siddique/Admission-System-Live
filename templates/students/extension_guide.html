Chrome & Edge Extension User Guide

Complete instructions for installing and using the Admission Board Verifier Extension for 100% automated SSC/HSC verification.

1. Download & Install Extension (30 Seconds)
v2.5.0 (Latest) Last Updated: Aug 13, 2026
Download Extension Package v2.5.0 (.ZIP)
  • 1
    Open Extensions Page in Browser:
    In Chrome, type chrome://extensions in address bar.
    In Edge, type edge://extensions in address bar.
  • 2
    Enable Developer Mode:
    Turn ON the "Developer mode" toggle switch in the top right corner.
  • 3
    Load Unpacked Extension:
    Click "Load unpacked" in the top left → select the extracted extension folder: scratch/board_verification_extension.
2. How to Use Daily Workflow
  • 1
    Copy Details in Admission System:
    On any student profile or directory queue, click Copy Details.
  • 2
    Open Board Website:
    Open eboardresults.com. The extension floating widget automatically appears in the top right corner!
    Admission Verifier READY

  • 3
    Click Auto-Fill & Solve Captcha:
    Click ⚡ Auto-Fill Form. All fields (Exam, Board, Year, Roll, Reg) populate instantly and focus cursor on Captcha. Type captcha & submit!
  • 4
    1-Click Result Sync:
    On the result page, click 🚀 Sync Result to Admission System. It auto-detects Student ID, extracts GPA, Name, Parents' Names, DOB, Gender, & Subject Grades (Physics, Chemistry, Math), and updates your server!

3. Server Configuration (Localhost vs Live Server)

By default, the extension connects to http://localhost:8000. If deploying to a live domain (e.g. https://portal.baust.edu.bd):

  1. Click the Extension puzzle icon in Chrome/Edge toolbar.
  2. Click Admission Board Result Auto-Sync.
  3. Enter your server URL (e.g. https://portal.baust.edu.bd) and click Save Settings.
Key Benefit: Extension runs completely in the background without needing browser bookmark clicks or popup prompts!
